# Committing and integration

Use worktree-session for repository ownership, output preservation and export
boundaries. Follow the repository's commit and verification requirements.

Reconcile with the authorized target before integrating. An explicit target pin
remains until its owner changes it. If that pin moves unexpectedly, hold the affected
integration and report the conflict. An unpinned moving target is ordinary integration
work within the shared agreement.

Resolve incompatible contributions with the responsible owner. Verify changed
interactions on the resulting candidate; the orchestrator judges where earlier
review no longer applies. A different commit hash alone does not invalidate an
unchanged review conclusion.

Advance the authorized destination with applicable review and any required user
acceptance. Report the resulting revision and actual delivery state through the
operating manual's record procedure.
