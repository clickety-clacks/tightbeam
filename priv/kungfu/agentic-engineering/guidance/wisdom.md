# Tightbeam wisdom — index

The numbered map of the project's design wisdom. Each rule's WORKING TEXT lives in
exactly one home (skill, manual, constitution, tenets); this index exists so reviews
and specs can cite "wisdom N" and so nothing gets re-derived. The decisions ledger
carries each rule's earning incident. Rule names are the gist; open the home for the
directive.
