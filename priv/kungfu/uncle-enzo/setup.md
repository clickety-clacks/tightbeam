# GitHub observer setup

The optional `uncle-enzo/github-watch` sentinel uses Python 3 and the GitHub CLI with a read-capable login. Configure its `GH_CONFIG_DIR` for the chosen host. Learning Enzo registers the declarations. Enabling the sentinel is a separate host action.

Elect the optional worker archetypes or the skills needed for the local practice. Keep elective rule templates in skills until the organization chooses to publish a copy with its own selectors. The sentinel makes GitHub reads for concrete demand only. With the sentinel disabled, roles can reconcile GitHub state directly.
