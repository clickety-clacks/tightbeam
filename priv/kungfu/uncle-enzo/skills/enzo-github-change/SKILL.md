---
name: enzo-github-change
description: Prepare a GitHub change or backport against the work item’s elected target.
---

Identify the base repository and full ref on the linked work. Identify the separately writable head repository and ref before making a change. A fork is a head location. The PR still belongs to the base repository.

Open or update a PR when the repository uses one. Record its canonical URL and the verified head OID. For a backport, link the source change to a distinct target and track its PR and evidence independently. Follow the repository's elected procedure for conflict resolution or direct push.
