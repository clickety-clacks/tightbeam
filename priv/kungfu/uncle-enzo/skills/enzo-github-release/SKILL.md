name: enzo-github-release
description: Read tag and publication evidence and perform assigned release actions.
---

Resolve the exact tag object and peeled commit. Check the candidate evidence and release readiness for the elected source. A tag observation establishes where a tag resolved. A corresponding release observation establishes publication, including whether it is a prerelease. Record both when the workflow uses both. Invoke a publishing action only within the delegated release authority.
