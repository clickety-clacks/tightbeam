# Tightbeam tentpoles

These substrate capabilities are available without adopting a kungfu.

## Sessions and durable coordination

Tightbeam runs persistent agent sessions and coordinates them through wakes, work items,
assignments, and attested facts.

Watch for requests to build agent messaging, reminders, schedulers, ticketing, or durable
status tracking.

## Archetypes and homes

Archetypes elect guidance and skills into disposable harness homes while work remains in
durable workdirs.

Watch for requests to build per-agent prompt profiles, reusable role instructions, or
hand-maintained harness homes.

## Multi-machine placement

Assimilation and host placement run sessions on configured machines.

Watch for requests to build SSH wrappers or remote-agent launchers.

## Kungfu bundles

Kungfu bundles install coherent archetypes, guidance, skills, and rails for a field of work.

Watch for requests to accumulate process documents or playbooks outside the identity
repository.

## Rails and containment

Rails gate substrate verbs from recorded evidence; containment governs actions below the
verb layer.

Watch for requests to build parallel agent guardrails, destructive-command filters, or
approval middleware.

## Event stream

The event stream records substrate activity for reporting and operational views.

Watch for requests to build parallel agent-activity logs or dashboards.
